# Riding Theory Booklet — my study copy

My personal, unofficial reading copy of the Singapore **Riding Theory Booklet**, plus a companion visual study guide for the Class 2B Riding Theory Test.

- **[Open my handbook copy](https://pwaaron.github.io/sg-riding-theory/handbook.html)**
- **[Open my study guide](https://pwaaron.github.io/sg-riding-theory/study-guide.html)**

## What this is

I rebuilt my copy of the booklet page by page as real HTML, CSS and inline SVG — not page screenshots. All 101 printed pages are present, together with the cover, page furniture, numbered rules, tables, and the original annotated figures traced into vector artwork with their source labels as native SVG text.

The companion study guide reorganises the same material for revision: high-frequency rules, decision flows, circuit-course diagrams and the numbers that are easy to mix up.

## Notes

- Single-file editions: fonts, styles and artwork are embedded, so each HTML file works offline and can be opened directly from disk.
- Wording, numbering and page order follow the printed booklet. Typography and colour are mine.
- This is a personal, non-commercial study project. **It is not affiliated with, endorsed by, or published by the Singapore Traffic Police.** Original booklet content © Singapore Traffic Police. Check the current official booklet and Traffic Police notices before your test.

## Deployment

The site is published from the `main` branch root with GitHub Pages. `.nojekyll` is included so the files are served as-is.
